## Widgets

A dashboard is a grid of widgets, each backed by a saved report: a chart, a single number, or a
table. Any saved report can be added to any number of dashboards, and updating the underlying report
updates every widget built from it.

## Sharing a dashboard

A dashboard can be shared with a specific role, a specific team, or the whole workspace, and sharing
does not change the underlying data permissions — a viewer without access to see certain deals will
see them omitted from shared widgets rather than seeing an error.

## Scheduled delivery

Any dashboard can be scheduled to email a snapshot image to a distribution list daily, weekly, or
monthly. The snapshot reflects live data at send time, and recipients without a Meridian account can
still receive the emailed image, though they cannot click through to the live dashboard.
